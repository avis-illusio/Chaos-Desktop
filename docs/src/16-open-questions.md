# 规格缺口与默认取值

交接文档已定稿语义，下列 16 处是写代码当天就会撞上的空白。**每条都已选定默认值并据此实现**；要改先改本节。

状态：`已定` = 已经拍板（含 D12）；`默认` = 按下方取值实现，有异议再改。

| ID | 缺口 | 取值 | 状态 |
|---|---|---|---|
| G1 | 多输出 / 工作区模型 | 每输出独立工作区集合；PZ 作用于聚焦输出；热插拔时窗口归主输出并按插入顺序重排 | 默认 |
| G2 | `.cdc` 词法细节 | 见 §`.cdc` 与解析器契约 的「词法决策」表 | 默认 |
| G3 | `@no-error-output` 索引基准 | 当前执行单元内、含指令自身、1 基、缩进块独立编号 | 默认 |
| G4 | 安全等级静态判定边界 | 子文件缺失 = 报错；环引用 = 报错；`xfile` 一律 general；不做 `# cdc-safety:` 文件头 | 默认 |
| G5 | 解析 vs 运行期错误恢复 | 解析失败整文件不执行；运行期错误继续；IPC 不可用中止 | 默认 |
| G6 | 诊断通道与退出码 | `stderr` / `--json` / `tracing` 三通道；退出码 0/1/2/3 | 默认 |
| G7 | IPC 协议细节 | `$CDC_SOCKET` → `$XDG_RUNTIME_DIR/chaos-desktop/ipc.sock`；socket 0600、目录 0700；`SO_PEERCRED` 校验同 uid；JSON-lines 握手带版本 | 默认 |
| G8 | `launch` 进程语义 | 允许空格分词、无 glob；默认直接 `posix_spawn`，`systemd-run` 可选；token 单次使用 60s；无 token 客户端 5s 内按最近 launch 给焦点 | 默认 |
| G9 | 配置项清单 v0.1 | 见配置系统契约的配置项表 | 默认 |
| G10 | 配置版本与迁移 | 顶层 `schema_version`，纯函数迁移链，迁移前快照，失败回退默认 | 默认 |
| G11 | 安全模式定义 | 连续 2 次启动失败触发；加载最近通过快照、跳 general 键、禁用 xfile、启 `--recovery` | 默认 |
| G12 | 快照策略 | `$XDG_STATE_HOME/chaos-desktop/snapshots/`，保留 20 份 | 默认 |
| G13 | PZ 精确定义 | 见决策 D12：画布 3×3，局部 1/9，全景 1/3 显示，Dock 不缩放，点击跳转 | **已定** |
| G14 | 性能预算 | 空闲 CPU < 1% / RSS < 150 MiB；帧 < 8ms（120Hz）；Dock 静态 < 3% | 默认 |
| G15 | 输入法与无障碍 | 阶段 2 预留 `text-input-v3` 扩展点；阶段 8 实现 IME；无障碍进 backlog | 默认 |
| G16 | 剪贴板与拖放 | v0.1 只做「接受 DnD 到 Dock 图标 + 落点高亮」；剪贴板保证 kitty ↔ PCManFM-Qt 可用 | 默认 |

## 交接文档「待确认事项」对账

| 交接文档 §10 | 结论 |
|---|---|
| 1. slint × layer-shell | 自建 `Platform` + `wl_shm`（D8），不等官方支持 |

## 仍未收敛、按默认值推进的两处

- **G1 多输出**：若将来要「工作区跨输出连续」，只需改工作区归属与 PZ 作用域，布局 trait 签名预留了 `outputs: &[OutputGeom]`。
- **G3 索引基准**：若改成「不含指令自身」，改动集中在预扫描的位置映射，执行器不受影响。
